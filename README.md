# Bank GraphQL API

A study API for banking operations built with GraphQL and TypeScript.

## Project goal

Practice domain modeling, schema-first API design and relational persistence through a small banking context.

## Features

- GraphQL queries and mutations
- Typed schema and resolvers
- Relational persistence with Prisma
- Validation at application boundaries

## Technologies

- **TypeScript**
- **Node.js**
- **Fastify**
- **Apollo Server**
- **TypeGraphQL**
- **Prisma**
- **GraphQL**

## What I learned

- Modeling a domain through GraphQL types and resolvers
- Connecting Apollo Server to Fastify
- Mapping selected GraphQL fields to database queries
- Validating input in a typed backend

## Running locally

```bash
npm install
npx prisma generate
npm run dev
```

## Project status

This is a learning and experimentation repository. It documents the concepts practiced at the time and is not presented as a production-ready application.
